# Northstar

Help find relevant job openings by monitoring job portals through crawling
and surfacing new openings relevant to my profile.

> Status: initial scaffold. Details on portals, profile matching, and

```bash
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
